**Test helper function:**
```rust
fn make_test_episode(episode_index: usize, num_frames: usize) -> Episode
```
Create a synthetic episode with:
- `num_frames` frames
- Action: 4-dim f64 values (deterministic: `(frame_idx * 4 + dim) as f64 * 0.1`)
- State: 4-dim f64 values (deterministic: `(frame_idx * 4 + dim) as f64 * 0.01`)
- One camera "observation.images.top": 4x4 RGB raw image (even dims for H.264 compat)
- Metadata: episode_index, task_index=0

```rust
fn make_test_dataset_info(num_episodes: usize, total_frames: usize) -> DatasetInfo
```

**Round-trip test pattern for each format:**
1. Create 2 episodes with 5 frames each using `make_test_episode()`
2. Get writer via `get_writer(format_name)`
3. Call `writer.set_deterministic(true)` for reproducibility
4. Write both episodes to a tempdir
5. Call `writer.finalize()`
6. Get reader via `get_reader(format_name)`
7. Read back episodes from tempdir
8. Assert episode count matches (2)
9. For each episode, assert frame count matches (5)
10. For numeric data (action, state): assert values match within epsilon (`(a - b).abs() < 1e-5` for f32 origin, `1e-10` for f64 origin, per pitfall 9)
11. For images: assert dimensions match (4, 4, 3)

**Individual round-trip tests:**
- `#[test] fn round_trip_lerobot_v3()` -- existing format, validates test harness works
- `#[test] fn round_trip_lerobot_v2()` -- no feature gate needed
- `#[cfg(feature = "rlds-format")] #[test] fn round_trip_rlds()`
- `#[cfg(feature = "hdf5-format")] #[test] fn round_trip_hdf5()`
- `#[cfg(feature = "zarr-format")] #[test] fn round_trip_zarr()`

- `#[cfg(feature = "robodm-format")] #[test] fn round_trip_robodm()`

**Additional integration tests:**

**Precision notes (from research pitfall 9):**

- Images: compare dimensions only (encoding/compression may not be bit-exact)
- For RoboDM: use `1e-4` epsilon (lower fidelity due to undocumented format)
