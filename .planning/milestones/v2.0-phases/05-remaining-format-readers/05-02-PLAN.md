Output: Two new reader modules (lerobot_v2, groot) with FormatReader and FormatDetector implementations.

<task type="auto">
  <name>Task 1: Implement LeRobot v2 reader</name>
  <files>crates/forge-formats/src/lerobot_v2/mod.rs, crates/forge-formats/src/lerobot_v2/reader.rs, crates/forge-formats/src/lerobot_v2/info.rs, crates/forge-formats/src/lib.rs</files>
  <action>
1. Create `crates/forge-formats/src/lerobot_v2/` directory with `mod.rs`, `reader.rs`, `info.rs`.

2. In `info.rs`:
   - Create `V2InfoJson` serde struct matching LeRobot v2 `meta/info.json` schema. Key differences from v3: `codebase_version` starts with "v2" or "2", v2 has one Parquet file per episode, v2 has one MP4 per episode per camera.
   - `is_lerobot_v2(path: &Path) -> bool`: check `meta/info.json` exists and `codebase_version` starts with "v2" or "2" (but NOT "v3" or "3").
   - `read_v2_info(path: &Path) -> ForgeResult<V2InfoJson>`: parse the info.json.
   - Implement `FormatDetector` for `LeRobotV2Detector`:
     - Confidence 0.9 if `meta/info.json` exists AND `codebase_version` starts with "v2" or "2"
     - Confidence 0.5 if `meta/info.json` exists but version unclear
     - Evidence: "meta/info.json found", "codebase_version: v2.x"

3. In `reader.rs`:
   - Create `LeRobotV2Reader` unit struct implementing `FormatReader`.
   - `format_name()` returns "lerobot-v2".
   - `can_read()` delegates to `is_lerobot_v2()`.
   - `inspect()`: parse v2 info.json, build `DatasetInfo` with fields from features, cameras from video features. Preserve all v2-specific metadata (e.g., `codebase_version`, `data_path` pattern).
   - `read_episodes()`: iterate over episodes. v2 stores data in per-episode Parquet files at `data/chunk-{chunk}/episode_{ep:06d}.parquet` (or similar pattern from v2 info). For each episode:
     a. Read the per-episode Parquet file using `parquet_io::read_parquet_file`
     b. Extract frame data (action, state, timestamps) from columns
     c. Create lazy video images pointing to per-episode MP4s at `videos/{camera_name}/episode_{ep:06d}.mp4`
     d. Preserve ALL fields from Parquet (including unknown ones) in frame metadata
     e. Keep original camera names as-is (per user decision)
     f. Timestamps preserved in original form (per user decision)
   - Handle lenient reading: if an episode's Parquet file is missing or corrupt, skip it with a ReadWarning, don't fail the entire dataset.

4. In `mod.rs`: re-export `reader::LeRobotV2Reader` and `info::LeRobotV2Detector`.

5. In `crates/forge-formats/src/lib.rs`: add `pub mod lerobot_v2;`.
  </action>
  <verify>
`cargo build -p forge-formats` compiles. Write unit tests in the reader module: test `is_lerobot_v2()` with mock directory structure (create temp dirs with meta/info.json containing v2 version string). Test that v3 datasets are NOT detected as v2.
  </verify>
  <done>LeRobotV2Reader implements FormatReader with can_read, inspect, and read_episodes. LeRobotV2Detector implements FormatDetector with scored detection. v2 datasets with per-episode Parquet and MP4 files are read correctly. All unknown fields preserved in metadata.</done>
</task>

2. In `reader.rs`:
   - Create `GR00TReader` struct that wraps a `LeRobotV2Reader` internally.
   - Implement `FormatReader`:
     - `format_name()` returns "groot".
     - `can_read()`: check if `is_lerobot_v2(path)` AND the dataset has NVIDIA-specific markers. Check `meta/info.json` for `robot_type` matching known NVIDIA identifiers (strings containing "GR1", "SO100", "Panda", or other GR00T robot types), OR the presence of `annotation.human.*` fields in the feature spec, OR any feature key starting with "annotation.".
     - `inspect()`: delegate to `LeRobotV2Reader::inspect()` but override `format` to "groot" in the returned DatasetInfo. Add GR00T-specific metadata.
     - `read_episodes()`: delegate entirely to `LeRobotV2Reader::read_episodes()`. GR00T datasets are structurally identical to LeRobot v2.
   - Implement `FormatDetector` for `GR00TDetector`:
     - Confidence 0.95 if `meta/info.json` exists, version is v2, AND NVIDIA robot_type or annotation fields found
     - Confidence 0.0 (return None) if no NVIDIA markers even if v2 dataset
     - Evidence: "LeRobot v2 format", "NVIDIA GR00T markers: robot_type={type}"
     - GR00T must be checked BEFORE LeRobot v2 in detection order (more specific)

3. In `mod.rs`: re-export `reader::GR00TReader` and `reader::GR00TDetector`.

4. In `crates/forge-formats/src/lib.rs`: add `pub mod groot;`.
