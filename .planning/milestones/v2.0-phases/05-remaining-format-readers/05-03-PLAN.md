2. In `layout.rs`, implement layout detection:
   ```rust
   #[derive(Debug, Clone, Copy, PartialEq, Eq)]
   pub enum HDF5Layout {
       Robomimic,  // Single file with /data/demo_N/ groups
       Aloha,      // /action, /observations/ at root or file-per-episode
   }
   ```
   - `detect_layout(file: &hdf5::File) -> ForgeResult<HDF5Layout>`:
     a. Check for `/data` group with keys matching `demo_*` pattern -> Robomimic
     b. Check for `/action` or `/observations` at root level -> ALOHA
     c. If neither matches, return error with descriptive message
   - `detect_layout_from_dir(path: &Path) -> ForgeResult<HDF5Layout>`:
     a. If path is a single .hdf5/.h5 file, open it and call detect_layout
     b. If path is a directory with multiple .hdf5/.h5 files, open the first one and detect

3. Implement robomimic reading helpers:
   - `read_robomimic_episodes(file: &hdf5::File) -> ForgeResult<Vec<String>>`: list all `/data/demo_*` keys
   - `read_robomimic_demo(file: &hdf5::File, demo_key: &str) -> ForgeResult<Episode>`:
     a. Open `/data/{demo_key}` group
     b. Read `actions` dataset: shape (T, action_dim) as f32/f64 -> LazyArray per frame
     c. Read `obs` group: iterate all sub-datasets. Known keys: `agentview_image`, `robot0_eef_pos`, `robot0_eef_quat`, `robot0_gripper_qpos`, `robot0_joint_pos`. Images stored as JPEG/PNG bytes or raw uint8 arrays.
     d. For image datasets in obs: check if data is 3D (T, H, W) or (T, H*W*C) for raw, or 1D compressed bytes. Use ImageEncoding::Jpeg if JPEG magic (0xFF 0xD8), ImageEncoding::Png if PNG magic (0x89 0x50), ImageEncoding::Raw otherwise.
     e. Read HDF5 attrs on the demo group (e.g., `num_samples`, `env_args`) -> episode.metadata
     f. Preserve ALL unknown datasets in obs as frame.metadata with their values as JSON

4. Implement ALOHA reading helpers:
   - `read_aloha_episode(file: &hdf5::File) -> ForgeResult<Episode>`:
     a. Read `/action` dataset: shape (T, action_dim)
     b. Read `/observations/qpos`, `/observations/qvel` as state arrays
     c. Read `/observations/images/{camera_name}` as image arrays
     d. Detect image encoding from byte content (same magic byte check)
     e. Preserve all attributes and unknown datasets as metadata

5. In `mod.rs`: re-export reader types (reader.rs will be created in Task 2).

6. In `crates/forge-formats/src/lib.rs`: add `#[cfg(feature = "hdf5-format")] pub mod hdf5;`.

<task type="auto">
  <name>Task 2: Implement HDF5 FormatReader and FormatDetector</name>
  <files>crates/forge-formats/src/hdf5/reader.rs, crates/forge-formats/src/hdf5/mod.rs</files>
  <action>
1. In `reader.rs`, create `HDF5Reader` unit struct implementing `FormatReader`:
   - `format_name()` returns "hdf5".
   - `can_read(path)`:
     a. If path is a file: check extension is .hdf5 or .h5, then verify HDF5 magic bytes (first 8 bytes: `\x89HDF\r\n\x1a\n`)
     b. If path is a directory: scan for .hdf5/.h5 files in the directory
   - `inspect(path)`:
     a. Open HDF5 file(s), detect layout
     b. For robomimic: count demo groups, sample first demo for schema (action dims, obs keys, image shapes)
     c. For ALOHA: count files or read single file dimensions
     d. Build DatasetInfo with fields, cameras, metadata
     e. Preserve env_args, env_name, and other top-level HDF5 attrs in metadata
   - `read_episodes(path)`:
     a. Detect layout
     b. For robomimic (single file): open file, iterate demo_0..demo_N, yield Episode per demo
     c. For ALOHA (directory): iterate .hdf5 files sorted by name, yield Episode per file
     d. Lenient reading: if a demo group is unreadable or an episode file is corrupt, emit ReadWarning and skip (per user decision)
     e. Union schema: if different episodes have different obs keys, merge all keys into superset (per user decision)

2. Implement `FormatDetector` for `HDF5Detector`:
   - Confidence scoring:
     a. File extension .hdf5/.h5: +0.4
     b. HDF5 magic bytes confirmed: +0.4
     c. Known layout detected (robomimic or ALOHA): +0.2
   - Evidence strings for each check
   - For directories: check if any .hdf5/.h5 files exist

3. In `mod.rs`: re-export `HDF5Reader` and `HDF5Detector`.

Note: Per research pitfall #1, the `hdf5` crate requires libHDF5 on the system. If `hdf5::File::open()` fails with a linking error, the error message should suggest installing libHDF5 (apt: libhdf5-dev, brew: hdf5).

  </verify>
