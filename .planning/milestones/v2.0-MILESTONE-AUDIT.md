## Tech Debt

### Phase 6: Remaining Format Writers (3 items)

- **Python interop validation deferred**: WRIT-02 through WRIT-06 require external Python tooling verification (tensorflow_datasets, h5py, zarr, ROS 2 tools, LeRobot library). Rust round-trip tests verify structural correctness; Python interop remains unvalidated.
- **Empty stats.json**: Both LeRobot v2 and v3 writers produce `stats.json` as `{}`. This is populated post-hoc by user tooling — intentional design decision.
- **RoboDM small image heuristic**: Test images below IMAGE_SIZE_THRESHOLD cause reader misclassification. Only affects synthetic test data; real-world images work correctly.

### Phase 5: Remaining Format Readers (4 items)

- **Placeholder stats.json**: Pre-existing from Phase 2 (lerobot_v3/writer.rs line 477)
- **HDF5 system dependency**: Requires system libHDF5; excluded from default features
- **zarrs version pin**: Pinned to 0.22 for MSRV compatibility (0.23 requires newer Rust)
- **Manual EBML parsing**: RoboDM uses hand-written VINT parser (undocumented schema prevents crate usage)
