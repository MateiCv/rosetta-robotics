**smoothness.rs** (QUAL-01 -- LDLJ smoothness):
Create `SmoothnessAccumulator` implementing `MetricAccumulator`:
- State: `window: Vec<[f64; 4]>` (per-dimension ring buffer of 4 position values), `window_pos: usize`, `window_filled: usize`, `jerk_sum_sq: f64` (Kahan-compensated running sum of ||jerk||^2 * dt), `kahan_comp: f64` (Kahan compensation term), `peak_vel_sq: f64` (running max of ||velocity||^2), `frame_count: usize`, `dt: f64`, `dims: usize`.
- `push_frame()`: Extract action slice. On first frame, initialize `dims` and `window` with `dims` rows. Insert action values into ring buffer at `window_pos`. Once `window_filled >= 4`, compute:
  - Velocity: `v[d] = (p[d][newest] - p[d][oldest]) / (3 * dt)` (span of 4 samples). Better: use the 4-sample third forward finite difference for jerk directly: `jerk[d] = (p3 - 3*p2 + 3*p1 - p0) / dt^3`.
  - Also compute velocity for peak tracking: `v[d] = (p[d][i] - p[d][i-1]) / dt` using the two most recent samples.
  - Call `simd::jerk_magnitude_sq(&jerk_vec)` to get ||jerk||^2.
  - Kahan sum: `y = jerk_sq * dt - kahan_comp; t = jerk_sum_sq + y; kahan_comp = (t - jerk_sum_sq) - y; jerk_sum_sq = t;`
  - Update `peak_vel_sq = max(peak_vel_sq, vel_sq)`.
  - Advance ring buffer: `window_pos = (window_pos + 1) % 4; window_filled = min(window_filled + 1, 4);`.
- `finalize()`:
  - If `frame_count < 4` or `peak_vel_sq < 1e-10`: return MetricResult with normalized_score=None, warning="insufficient data" or "no motion detected".
  - `T = frame_count as f64 * dt; V_peak = peak_vel_sq.sqrt();`
  - `ldlj = -(T.powi(3) / V_peak.powi(2) * jerk_sum_sq).ln();`
  - Normalize to 0-1: Higher LDLJ (more negative ln) = smoother. Use sigmoid-like normalization: `score = 1.0 / (1.0 + (-ldlj / scale).exp())` where scale is a tuning parameter (use 5.0 as default). Alternatively, use the simpler approach: clamp ldlj to a known range and linearly map. Research suggests LDLJ values typically range from -10 (very jerky) to 0 (very smooth). Map: `score = (ldlj.clamp(-10.0, 0.0) + 10.0) / 10.0`.
  - Return MetricResult with kind=Smoothness, normalized_score=Some(score), raw_value=Some(ldlj), details=MetricDetails::Smoothness { ldlj_value: ldlj }.
- `score_bounds()`: Return (0.0, 1.0) -- LDLJ cannot bound early without domain knowledge.

**dead_actions.rs** (QUAL-02 -- dead action detection):
Create `DeadActionsAccumulator` implementing `MetricAccumulator`:
- State: `first_action: Option<Vec<f64>>`, `dead_frame_count: usize`, `total_frames: usize`, `dims: usize`, `dead_threshold: f64` (1e-6).
- `push_frame()`: Extract action. On first frame with action, clone into `first_action`. On subsequent frames, check if all dims are within `dead_threshold` of first_action values AND within `dead_threshold` of zero. If so, increment `dead_frame_count`. Increment `total_frames`.
- `finalize()`: `dead_ratio = dead_frame_count as f64 / total_frames.max(1) as f64`. Score: `1.0 - dead_ratio` (0 = all dead, 1 = no dead). If no frames: score=None.
- `score_bounds()`: After N frames with K dead, `min = 1.0 - ((K + remaining) as f64 / total.max(1) as f64)`, `max = 1.0 - (K as f64 / total.max(1) as f64)`. But we don't know total in advance. Default to (0.0, 1.0).

**chatter.rs** (QUAL-03 -- gripper chatter):
Create `ChatterAccumulator` implementing `MetricAccumulator`:
- State: `prev_gripper_binary: Option<bool>`, `transitions: usize`, `frame_count: usize`, `gripper_dim: Option<usize>`, `gripper_threshold: f64` (0.5 -- values > threshold = open, <= = closed), `dt: f64`.
- Constructor takes `gripper_dim: Option<usize>` from QualityConfig. If None, use last action dimension.
- `push_frame()`: Extract action. Determine gripper dim (config or `action.len() - 1`). Get gripper value, binarize (> threshold = true). If `prev_gripper_binary` exists and differs from current: `transitions += 1`. Update prev. Increment frame_count.
- `finalize()`: If no action data available, return score=None, warning="skipped, no gripper data". `rate = transitions as f64 / (frame_count as f64 * dt)`. Normalize: low rate = good (no chatter). Use: `score = 1.0 / (1.0 + rate / rate_scale)` where `rate_scale = 2.0` (transitions per second). Or simpler: `score = (1.0 - (rate / max_rate).clamp(0.0, 1.0))` where `max_rate = 10.0` transitions/sec. Return with details=GripperChatter { transitions, rate }.
- `score_bounds()`: Can bound based on current rate vs remaining frames.

- `score_bounds()`: Boundable same as dead actions.

**timestamps.rs** (QUAL-05 -- timestamp regularity):
Create `TimestampsAccumulator` implementing `MetricAccumulator`:
- State: `prev_timestamp: Option<f64>`, `welford_count: usize`, `welford_mean: f64`, `welford_m2: f64` (Welford online variance), `gap_count: usize`, `expected_dt: f64`, `gap_threshold_factor: f64` (2.0 -- gaps > 2x expected dt are counted).
- Constructor takes `expected_dt: f64` (1.0 / fps).
- `push_frame()`: Extract timestamp from `ctx.timestamp`. If `prev_timestamp` exists: compute `dt = timestamp - prev_timestamp`. Welford update: `count += 1; delta = dt - mean; mean += delta / count; delta2 = dt - mean; m2 += delta * delta2;`. If `dt > expected_dt * gap_threshold_factor`: `gap_count += 1`. Update `prev_timestamp`.
- `finalize()`: If `welford_count < 2`: return None. `variance = m2 / (welford_count - 1); std = variance.sqrt(); jitter_ratio = std / welford_mean.abs().max(1e-10);`. Normalize: low jitter = good. `score = (1.0 - jitter_ratio.clamp(0.0, 1.0)).max(0.0)`. If no timestamps available, return None with warning "skipped, no timestamp data". Return with details=TimestampRegularity { mean_dt: welford_mean, std_dt: std, jitter_ratio, gap_count }.
- `score_bounds()`: After ~20 frames, jitter ratio converges. Return tight bounds based on current jitter.

**saturation.rs** (QUAL-06 -- action saturation):
Create `SaturationAccumulator` implementing `MetricAccumulator`:
- State: `min_vals: Vec<f64>`, `max_vals: Vec<f64>`, `saturated_count: usize`, `total_count: usize`, `dims: usize`, `saturation_threshold: f64` (0.95 -- fraction of range at which action is "saturated").
- `push_frame()`: Extract action. On first frame, initialize `min_vals` and `max_vals` from action values, set `dims`. On subsequent frames, update per-dim min/max. Check if any dimension's value is within `saturation_threshold` fraction of its current observed range extremes. Specifically: for each dim, if `(action[d] - min_vals[d]) / (max_vals[d] - min_vals[d]) > saturation_threshold` or `< (1.0 - saturation_threshold)`: count as saturated. Actually simpler: track how many frames have at least one dimension at its min or max (within epsilon). Better approach: after all frames, compute fraction of frames where any dim is within 5% of its range boundary.
- Alternative (simpler, per research): Count frames where `|action[d]| > saturation_limit` for any d. Use absolute saturation limit of +-1.0 (common for normalized robot actions) or compute from observed range.
- Best approach matching Python: Track running min/max per dim. A frame is "saturated" if any dim's value equals (within epsilon 1e-6) the running min or max observed so far. After finalize, `saturated_ratio = saturated_count / total_count`.
- `finalize()`: `score = 1.0 - saturated_ratio`. Return with details=ActionSaturation { saturated_ratio }.

**entropy.rs** (QUAL-07 -- action entropy):
Create `EntropyAccumulator` implementing `MetricAccumulator`:
- State: `values: Vec<Vec<f64>>` (buffered per-dimension action values -- O(T*D) memory, acceptable per research decision), `dims: usize`, `frame_count: usize`.
- `push_frame()`: Extract action. On first frame, initialize `dims` and `values` with `dims` empty Vecs. Push each action[d] into `values[d]`. Increment `frame_count`.
- `finalize()`: If `frame_count < 2` or `dims == 0`: return None. For each dimension:
  - Compute range: `min = values[d].min(); max = values[d].max();`
  - If range < 1e-10: entropy for this dim = 0.0 (constant-valued -- no diversity).
  - Else: compute histogram using `simd::histogram_bin_assign(&values[d], min, bin_width, n_bins)` where `n_bins = (frame_count as f64).log2().ceil() as usize + 1` (Sturges' rule, min 2).
  - Compute probabilities: `p[i] = counts[i] as f64 / frame_count as f64`.
  - Compute entropy: `simd::entropy_sum(&probabilities)`.
  - Max possible entropy for n_bins bins: `max_entropy = (n_bins as f64).log2()`.
  - Normalized dim entropy: `dim_entropy / max_entropy` (0-1 range).
- Average normalized entropy across dimensions = `mean_entropy`.
- Score = `mean_entropy` (higher entropy = more diverse actions = better).
- Return with details=ActionEntropy { mean_entropy }.
- Note: entropy buffering is O(T*D) which is acceptable per research recommendation (max ~1.6MB per episode for 10K frames x 20 dims).
