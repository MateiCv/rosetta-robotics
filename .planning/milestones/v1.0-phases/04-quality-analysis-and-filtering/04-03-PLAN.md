**composite.rs** (QUAL-08):
Create composite score computation module:

`pub fn composite_score(scores: &[(MetricKind, Option<f64>)], weights: &HashMap<MetricKind, f64>) -> Option<f64>`:
- Iterate over (kind, score) pairs.
- For each Some(score), look up weight in weights map (default 0.0 if missing).
- Accumulate `weighted_sum += score * weight` and `total_weight += weight`.
- None scores are skipped (weight redistributed by simply not adding to total_weight).
- If `total_weight > 0.0`: return `Some(weighted_sum / total_weight)`. Score stays in 0.0-1.0 range.
- If `total_weight == 0.0`: return `None` (all metrics skipped).
- Per user decision: this produces 0.0-1.0 composite (NOT 0-10 like Python).

`pub fn composite_bounds(accumulators: &[Box<dyn MetricAccumulator>], weights: &HashMap<MetricKind, f64>) -> (f64, f64)`:
- For each accumulator, call `score_bounds()` to get `(min, max)`.
- Compute `min_composite = sum(min[i] * w[i]) / sum(w[i])`.
- Compute `max_composite = sum(max[i] * w[i]) / sum(w[i])`.
- Return `(min_composite, max_composite)`.

Add `pub mod composite;` to metrics/mod.rs.

Unit tests:
- All scores present: weighted average matches manual computation.
- Some None scores: weight redistributed correctly, result still in 0-1.
- All None: returns None.
- All scores 1.0: composite = 1.0.
- All scores 0.0: composite = 0.0.

**early_exit.rs** (QUAL-14):
Create early exit decision logic:

`pub enum EarlyExitDecision { Pass, Fail, Continue }`

`pub fn check_early_exit(accumulators: &[Box<dyn MetricAccumulator>], weights: &HashMap<MetricKind, f64>, threshold: f64) -> EarlyExitDecision`:
- Call `composite_bounds(accumulators, weights)` to get `(min_composite, max_composite)`.
- If `min_composite >= threshold`: `EarlyExitDecision::Pass` -- episode definitely passes.
- If `max_composite < threshold`: `EarlyExitDecision::Fail` -- episode definitely fails.
- Otherwise: `EarlyExitDecision::Continue`.

Add `pub mod early_exit;` to lib.rs.

- Accumulators all returning bounds (0.0, 0.3) with threshold 0.5: should be Fail.
- Accumulators with mixed wide bounds: should be Continue.

`impl QualityAnalyzer`:

`pub fn new(config: QualityConfig) -> Self`

`pub fn analyze_episode(&self, episode: &Episode, dataset_fps: Option<f64>) -> EpisodeQuality`:
- Create accumulators via `create_accumulators(&self.config)`.
- Determine dt: `1.0 / self.config.fps.or(dataset_fps).unwrap_or(30.0)`.
- Iterate over `episode.frames`:
  - For each frame, extract action and state:
    - `let action_data = frame.action.as_ref().and_then(|a| a.load().ok());`
    - `let state_data = frame.state.as_ref().and_then(|s| s.load().ok());`
    - Extract timestamp: `frame.metadata.get("timestamp").and_then(|v| v.as_f64())`. Fall back to `frame.timestep as f64 * dt`.
  - Build `FrameContext { frame_index: frame.timestep, action: action_data.map(|v| v.as_slice()), state: state_data.map(|v| v.as_slice()), timestamp: Some(ts), dt }`.
  - Push to all accumulators: `for acc in &mut accumulators { acc.push_frame(&ctx); }`.
  - If `self.config.composite_threshold` is Some, check early exit after every 10 frames (not every frame -- overhead): call `check_early_exit(&accumulators, &weights, threshold)`. On Pass or Fail, break the frame loop early.
- After all frames (or early exit), finalize: `let results: Vec<MetricResult> = accumulators.iter_mut().map(|a| a.finalize()).collect();`
- Compute composite: call `composite_score()` with results and config weights.
- Build `EpisodeQuality`:
  - `episode_id: episode.episode_id.clone()`
  - `num_frames: episode.frames.len()`
  - `duration_secs`: compute from timestamps or `frames.len() as f64 * dt`
  - `cameras`: `episode.frames.first().map(|f| f.image_names()).unwrap_or_default().iter().map(|s| s.to_string()).collect()`
  - `composite_score`: from composite calculation
  - `metric_scores`: HashMap from MetricKind display name -> MetricScore { normalized, raw, warning }
  - `flags`: collect warnings/flags from each metric result (e.g., if dead_ratio > 0.5 add "dead actions detected")
- **CRITICAL: Do NOT load images during quality analysis.** Only access frame.action, frame.state, and frame.metadata. Never call frame.images[].load().

`pub fn analyze_dataset(&self, reader: &dyn FormatReader, path: &std::path::Path) -> ForgeResult<QualityReport>`:
- Call `reader.inspect(path)` to get DatasetInfo for fps and metadata.
- Call `reader.read_episodes(path)` to get episode iterator.
- Iterate episodes, calling `analyze_episode()` for each.
- Collect into `Vec<EpisodeQuality>`.
- Compute overall_score: mean of non-None composite scores.
- Build `QualityReport`:
  - `dataset_path: path.display().to_string()`
  - `num_episodes: per_episode.len()`
  - `overall_score`
  - `computed_at`: current UTC time as ISO 8601 string (use `std::time::SystemTime` -> format manually or use a simple helper)
  - `per_episode`
  - `flags`: dataset-level flags (e.g., "N episodes have quality below 0.5")
  - `recommendations`: empty for now

`pub fn export_json(&self, report: &QualityReport) -> ForgeResult<String>`:
- `serde_json::to_string_pretty(report).map_err(|e| ForgeError::Config(format!("JSON export failed: {e}")))`

`pub fn save_json(&self, report: &QualityReport, path: &std::path::Path) -> ForgeResult<()>`:
- Write JSON to file at `path`. Per user decision: `--save` writes `quality.json` to dataset dir.
