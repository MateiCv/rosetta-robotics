1. Create `crates/forge-formats/src/lerobot_v3/writer.rs`:

   **Struct:**
   ```rust
   pub struct LeRobotV3Writer {
       config: VideoEncoderConfig,
       chunks_size: usize,           // episodes per chunk (default 1000)
       fps: u32,
       robot_type: String,
       // Accumulated state during writing
       episodes_written: Vec<EpisodeMetadata>,
       total_frames: usize,
       features: Option<HashMap<String, FeatureSpec>>,
       tasks: Vec<String>,           // task descriptions
   }
   ```

   **`impl FormatWriter for LeRobotV3Writer`:**

   **`format_name(&self) -> &str`:** Return `"lerobot-v3"`.

   **`write_episode(&mut self, episode: &Episode, output_path: &Path, episode_index: usize) -> ForgeResult<()>`:**
   - Determine chunk_index = episode_index / chunks_size, file_index = 0
   - Create output directories: `data/chunk-{chunk_index:03d}/`, `videos/{camera}/chunk-{chunk_index:03d}/`
   - **Parquet data writing:**
     - Build Arrow schema with: episode_index (Int64), frame_index (Int64), index (Int64), timestamp (Float32), task_index (Int64), action (FixedSizeList<Float32, N>), observation.state (FixedSizeList<Float32, N>)
     - Infer action_dim and state_dim from the first frame's data dimensions
     - On first episode: capture the features schema for info.json generation
     - Build RecordBatch from episode frames:
       - episode_index: repeated for all frames
       - frame_index: 0..frame_count
       - index: global offset (self.total_frames) + 0..frame_count
       - timestamp: frame_index / fps (as f32)
       - task_index: from episode metadata, default 0
       - action: FixedSizeListArray<Float32> built with FixedSizeListBuilder
       - observation.state: same pattern
     - Use `FixedSizeListBuilder<Float32Builder>` for vector columns (see RESEARCH.md Pitfall 1 -- MUST use FixedSizeList, NOT flat Float32)
     - Append to or create Parquet file at `data/chunk-{chunk_index:03d}/file-{file_index:03d}.parquet` using ArrowWriter
     - For Phase 2 simplicity: one episode per Parquet file (chunks_size effectively 1). This matches the Python Forge writer behavior.

   - **Video encoding:**
     - For each camera in the episode:
       - Create `H264VideoEncoder` with the configured parameters (CRF, preset, etc.)
       - Iterate frames, load each LazyImage, encode the RGB data
       - Call `finish()` to flush and close
       - **CRITICAL (VID-05):** Assert that `encoder.finish()` return value (frame count) equals the number of Parquet rows for this episode. If mismatch, return `ForgeError::Video("frame count mismatch")`
       - Write MP4 to `videos/{camera_key}/chunk-{chunk_index:03d}/file-{file_index:03d}.mp4`

   - **Episode metadata tracking:**
     - Record `EpisodeMetadata { episode_index, length: frame_count, task_index }`
     - Increment `self.total_frames += frame_count`

   **`finalize(&mut self, output_path: &Path, dataset_info: &DatasetInfo) -> ForgeResult<()>`:**
   - **Write `meta/info.json`:**
     - Build `InfoJson` struct with:
       - `codebase_version: "v3.0"`
       - `robot_type` from config or dataset_info
       - `total_episodes`, `total_frames`, `total_tasks` from accumulated state
       - `chunks_size`: use configured value
       - `fps` from config
       - `splits: { "train": "0:{total_episodes}" }`
       - `data_path: "data/chunk-{chunk_index:03d}/file-{file_index:03d}.parquet"`
       - `video_path: "videos/{video_key}/chunk-{chunk_index:03d}/file-{file_index:03d}.mp4"`
       - `features`: Build from captured schema:
         - Action/state: dtype "float32", shape [N], names from field schema or null
         - Video cameras: dtype "video", shape [H, W, 3], with full `info` dict including `video.fps`, `video.codec` ("h264"), `video.pix_fmt` ("yuv420p"), `video.is_depth_map` (false), `has_audio` (false)
         - Index columns: timestamp (float32, [1]), frame_index (int64, [1]), episode_index (int64, [1]), index (int64, [1]), task_index (int64, [1])
     - Serialize with serde_json and write to `meta/info.json`
     - **CRITICAL (Pitfall 4, Pitfall 5):** Include ALL fields in info.json, especially the video `info` sub-dict

   - **Write `meta/episodes/chunk-{:03d}/file-{:03d}.parquet`:**
     - Build Arrow RecordBatch with episode_index, length, task_index columns
     - Write as Parquet to the episode metadata directory

   - **Write `meta/tasks.jsonl`:**
     - Write one JSON line per task: `{"task_index": 0, "task": "default_task"}`

   - **Write `meta/stats.json`:**
     - Write empty/placeholder stats (or compute basic min/max/mean/std per feature from accumulated data)
     - This file is optional for LeRobotDataset loading but good practice

     - `errors: Vec<String>`
   - `pub struct Converter` with:
     - `config: ConversionConfig`
   - `impl Converter`:
     - `pub fn new(config: ConversionConfig) -> Self`
     - `pub fn convert(&self, source_path: &Path, output_path: &Path) -> ForgeResult<ConversionResult>`:
       1. Detect source format: `forge_formats::registry::detect_format(source_path)?` (or use `config.source_format` if set)
       2. Get reader: `forge_formats::registry::get_reader(format_name)?`
       3. Determine target format: `config.target_format` (required, error if not set)
       4. Get writer: `forge_formats::registry::get_writer(target_format)?`
       5. Inspect source: `reader.inspect(source_path)?` -> `DatasetInfo`
       6. Iterate episodes: `reader.read_episodes(source_path)?`
       7. For each episode:
          - Apply field remapping from `config.fields` (rename action/state fields if configured)
          - Apply camera remapping from `config.cameras` (rename camera keys if configured)
          - Call `writer.write_episode(&episode, output_path, episode_index)?`
          - Track success/failure (if `config.fail_on_error` is false, catch errors and continue)
       8. Call `writer.finalize(output_path, &dataset_info)?`
       9. Return `ConversionResult`
