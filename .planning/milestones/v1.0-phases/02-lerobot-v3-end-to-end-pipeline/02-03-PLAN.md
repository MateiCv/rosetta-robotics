<objective>
Implement the LeRobot v3 dataset reader: parse info.json metadata, read Parquet data files using Arrow, decode video frames, and produce Episode/Frame objects.

Purpose: The reader is the first half of the LeRobot v3 pipeline. Without it, there is no source data to convert. This plan delivers the ability to read any LeRobot v3 dataset from disk into Forge's canonical Episode/Frame representation.

Output: `LeRobotV3Reader` implementing `FormatReader`, with supporting modules for info.json parsing and Parquet I/O.
</objective>

  <name>Task 2: Implement LeRobotV3Reader</name>
  <files>
    crates/forge-formats/src/lerobot_v3/reader.rs

  <action>
1. Create `crates/forge-formats/src/lerobot_v3/reader.rs`:
   - `pub struct LeRobotV3Reader;` (stateless, all state passed via method args)
   - `impl FormatReader for LeRobotV3Reader`:

   **`format_name(&self) -> &str`:** Return `"lerobot-v3"`.

   **`can_read(&self, path: &Path) -> bool`:** Delegate to `info::is_lerobot_v3(path)`.

   **`inspect(&self, path: &Path) -> ForgeResult<DatasetInfo>`:**
   - Read info.json via `info::read_info(path)`
   - Convert to DatasetInfo:
     - `format: "lerobot-v3"`
     - `path: path.to_path_buf()`
     - `total_episodes` and `total_frames` from info.json
     - `fps: Some(info.fps as f64)`
     - `robot_type: Some(info.robot_type.clone())`
     - Build `fields: Vec<FieldSchema>` from non-video features (map dtype string to Dtype enum, shape from feature shape)
     - Build `cameras: Vec<CameraInfo>` from video features (extract height/width from video.info or shape)
     - Store extra metadata in the `metadata` HashMap (e.g., `chunks_size`, `codebase_version`)

   **`read_episodes(&self, path: &Path) -> ForgeResult<Box<dyn Iterator<Item = ForgeResult<Episode>>>>`:**
   - Read info.json and episode metadata
   - Read all data Parquet files for the dataset (iterate over chunks based on total_episodes and chunks_size)
   - For each episode in episode metadata:
     - Extract the episode's rows from Parquet data using `extract_episode_data`
     - Build `Episode` with `episode_id = episode_index.to_string()`
     - Build `Frame`s from the extracted data:
       - `timestep` = frame_index value
       - `action` = `LazyArray::from_vec()` with the action values for this frame (convert f32 to f64 for LazyArray compatibility)
       - `state` = `LazyArray::from_vec()` with the state values
       - `images`: For each video feature, create a `LazyImage` with a closure that:
         - Identifies the correct MP4 file path using `info.resolve_video_path()`
         - Uses `forge_video::VideoDecoder` to decode the specific frame
         - Returns the RGB pixel data as `Bytes`
         - The lazy loading means video frames are only decoded when accessed
       - Store `timestamp` in frame metadata
     - Add episode-level metadata (`task_index`)
   - Return a boxed iterator over episodes

   **Important implementation notes:**
   - LazyArray stores `Vec<f64>`, but Parquet has `Vec<f32>`. Convert f32->f64 during extraction.
   - Video frames should use truly lazy loading (closure captures the file path and frame index, decodes on demand).
   - For Phase 2 simplicity, read all Parquet data upfront (not streaming). Streaming optimization comes in Phase 3.
   - Handle the case where a dataset has no video features (tabular-only dataset).

2. Update `crates/forge-formats/src/registry.rs`:
   - Update `detect_format` to actually call `LeRobotV3Reader.can_read(path)` and return `"lerobot-v3"` if true.
   - Add `pub fn get_reader(format_name: &str) -> ForgeResult<Box<dyn FormatReader>>` that returns `Box::new(LeRobotV3Reader)` for "lerobot-v3".
  </action>
