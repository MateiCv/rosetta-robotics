<task type="auto">
  <name>Task 2: Implement H264VideoEncoder and VideoDecoder</name>

  <action>
**Encoder (`encoder.rs`):**
1. Create `H264VideoEncoder` struct holding output path, config, frame count, and internal FFmpeg state.
2. Implement `new(output_path: &Path, config: &VideoEncoderConfig) -> ForgeResult<Self>`:
   - Call `ffmpeg::init()` (idempotent)
   - Create `format::output(&output_path)` for the MP4 container
   - Find H264 encoder via `codec::encoder::find_by_name(&config.codec)`
   - Add a video stream, configure encoder parameters:
     - `set_width`, `set_height`, `set_format(Pixel::YUV420P)`, `set_time_base`, `set_frame_rate`, `set_gop(config.gop_size)`
   - Open encoder with `Dictionary` containing `"crf" => config.crf` and `"preset" => config.preset`
   - Write output header
3. Implement `encode_frame(&mut self, rgb_data: &[u8]) -> ForgeResult<()>`:
   - Create an RGB24 `Video` frame, copy pixel data in
   - Convert RGB24 -> YUV420P using `software::scaling::Context`
   - Set PTS based on frame count
   - Send frame to encoder, receive and write packets
   - Increment frame count
4. Implement `force_keyframe_next(&mut self)`:
   - Set a flag that on the next `encode_frame` call, the frame is marked as a keyframe (set `AV_PKT_FLAG_KEY` or use `frame.set_kind(picture::Type::I)`)
   - This satisfies VID-06 (keyframes at episode boundaries)
5. Implement `finish(mut self) -> ForgeResult<usize>`:
   - Flush encoder by sending None frame
   - Drain remaining packets
   - Write output trailer
   - Return total frame count encoded
6. Wrap all FFmpeg errors into `ForgeError::Video(msg)`.

**Decoder (`decoder.rs`):**
1. Create `VideoDecoder` struct.
2. Implement `open(path: &Path) -> ForgeResult<Self>`:
   - Open input via `format::input(path)`
   - Find the best video stream index
   - Create a decoder context from the stream's codec parameters
   - Create a scaler context for converting decoded pixel format -> RGB24
3. Implement `Iterator` yielding `ForgeResult<DecodedFrame>` where `DecodedFrame` has:
   - `data: Vec<u8>` (RGB24 pixels)
   - `width: u32`, `height: u32`
   - `frame_index: usize`
4. The iterator reads packets from the input, sends to decoder, receives frames, scales to RGB24, and yields them.
5. Implement `frame_count(&self) -> Option<usize>` that returns the total frame count from stream metadata if available.
6. Implement `width(&self) -> u32` and `height(&self) -> u32` from the stream parameters.

**Important notes from research:**
- Always flush the encoder (send None) to drain B-frame buffers -- without this, last 1-2 frames per episode will be lost (Pitfall 7).
- The decoder must handle any codec FFmpeg supports (H.264, AV1, etc.) -- codec detection is automatic from the container.
- Use `software::scaling::Context` (swscale) for pixel format conversion in both encoder (RGB24->YUV420P) and decoder (any->RGB24).
- The scaler must be created with the correct input/output dimensions and pixel formats.
  </action>
