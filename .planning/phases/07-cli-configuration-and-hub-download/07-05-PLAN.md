    1. Create `crates/forge-cli/src/commands/export_video.rs`:
       - `pub fn run(path: &str, output_dir: &str, episodes: Option<&str>, camera: Option<&str>, fps: Option<f64>) -> anyhow::Result<()>`:
         - Resolve path and auto-detect format (handles hf:// URLs transparently):
           `let (resolved_path, format_name) = crate::output::resolve_and_detect(path)?;`
         - Get reader: `let reader = forge_formats::get_reader(&format_name)?;`
         - Inspect dataset for camera info and FPS: `reader.inspect(&resolved_path)?`
         - Use dataset FPS or CLI override: `let video_fps = fps.unwrap_or(info.fps.unwrap_or(30.0));`
         - Read episodes: `reader.read_episodes(&resolved_path)?`
         - If `episodes` arg is specified (e.g., "0,1,5" or "0-5"), parse episode indices/ranges and filter
         - Create output directory: `std::fs::create_dir_all(output_dir)?`
         - For each episode:
           - Determine which cameras to export:
             - If `camera` specified, export only that camera
             - Otherwise export all cameras from the first frame
           - For each camera:
             - Get image dimensions from the first frame's LazyImage: `image.width`, `image.height`, `image.channels`, `image.encoding`
             - Create encoder config: `let config = forge_video::VideoEncoderConfig::new(image.width, image.height, video_fps);`
             - Create encoder: `let mut encoder = forge_video::H264VideoEncoder::new(&output_path, &config)?;`
             - For each frame in the episode:
               - Load image data: `let bytes = frame.images.get(camera_name).unwrap().load()?;`
               - **Handle image encoding**: The image may be Raw RGB, JPEG, or PNG. If `image.encoding` is:
                 - `ImageEncoding::Raw` and `channels == 3`: pass `bytes` directly to `encoder.encode_frame(bytes)`
                 - `ImageEncoding::Jpeg` or `ImageEncoding::Png`: decode to raw RGB first using the `image` crate:
                   `let img = image::load_from_memory(bytes)?.to_rgb8(); encoder.encode_frame(img.as_raw())?;`
                 - Add `image = "0.25"` to forge-cli Cargo.toml for JPEG/PNG decoding
               - Call `encoder.encode_frame(&rgb_data)?;` (expects exactly width*height*3 bytes of packed RGB24)
             - Finalize: `let count = encoder.finish()?;` (flushes buffered frames, writes trailer, returns frame count)
             - Output filename: `{output_dir}/{episode_id}_{camera_name}.mp4`
           - Print progress: `eprintln!("Exported: {} ({} frames)", output_filename, count)`
         - Print summary: `eprintln!("Exported {} videos to {}", total_count, output_dir)`

       - `fn parse_episode_selection(spec: &str) -> anyhow::Result<Vec<usize>>`:
         - Parse comma-separated indices and ranges: "0,1,5" -> [0,1,5], "0-5" -> [0,1,2,3,4,5], "0,3-5,9" -> [0,3,4,5,9]
         - Error on invalid format

       - **Encoder API reference** (from `crates/forge-video/src/encoder.rs`):
         - `VideoEncoderConfig::new(width: u32, height: u32, fps: f64)` — creates config with locked defaults (libx264, CRF 23, medium preset)
         - `H264VideoEncoder::new(output_path: &Path, config: &VideoEncoderConfig)` -> `ForgeResult<Self>`
         - `encoder.encode_frame(rgb_data: &[u8])` -> `ForgeResult<()>` — rgb_data must be exactly width*height*3 bytes RGB24
         - `encoder.finish(self)` -> `ForgeResult<usize>` — MUST be called to flush B-frame buffer and write trailer, returns total frame count
