       - `pub fn is_hf_url(path: &str) -> bool` — returns true if path starts with `hf://`, `huggingface://`, or contains `huggingface.co/datasets/`
       - `pub struct HfRef { pub repo_id: String, pub revision: Option<String>, pub subpath: Option<String> }`
       - `pub fn parse_hf_url(url: &str) -> anyhow::Result<HfRef>`:
         - Strip prefix (`hf://`, `huggingface://`, or `https://huggingface.co/datasets/`)
         - Parse `org/repo` (required), optional `@revision` (e.g., `hf://lerobot/aloha@main`), optional `/subpath`
         - Examples: `hf://lerobot/aloha` -> `HfRef { repo_id: "lerobot/aloha", revision: None, subpath: None }`
         - Error if no `/` in repo part: "Invalid HuggingFace URL: expected format hf://org/repo"

    3. Implement path resolution:
       - `pub fn resolve_path(path: &str) -> anyhow::Result<std::path::PathBuf>`:
         - If `is_hf_url(path)` -> call `download_dataset(path)`
         - Otherwise -> `Ok(PathBuf::from(path))`
         - This function is the single entry point for ALL path-accepting commands

    4. Implement dataset download:
       - `pub fn download_dataset(url: &str, token: Option<&str>) -> anyhow::Result<std::path::PathBuf>`:
         - Parse URL: `let hf_ref = parse_hf_url(url)?;`
         - Build API:
           ```rust
           let mut builder = hf_hub::api::sync::ApiBuilder::new();
           // If a token was explicitly provided (via --token or HF_TOKEN env), pass it.
           // Otherwise hf-hub's default builder reads ~/.cache/huggingface/token automatically.
           if let Some(t) = token {
               builder = builder.with_token(Some(t.to_string()));
           }
           let api = builder.build().context("failed to initialize HuggingFace Hub API")?;
           let repo = api.dataset(hf_ref.repo_id.clone());
           ```
         - Enumerate files:
           ```rust
           let info = repo.info().map_err(|e| {
               // Check for auth errors and provide helpful message
               let msg = format!("{e}");
               if msg.contains("401") || msg.contains("403") || msg.contains("Unauthorized") || msg.contains("Forbidden") {
                   anyhow::anyhow!(
                       "Authentication required for '{}'. Set HF_TOKEN environment variable or run `huggingface-cli login`.\nOriginal error: {e}",
                       hf_ref.repo_id
                   )
               } else {
                   anyhow::anyhow!("Failed to fetch repo info for '{}': {e}", hf_ref.repo_id)
               }
           })?;
           ```
         - Filter files: if `hf_ref.subpath` is Some, only download files under that subpath
         - Download with progress:
           ```rust
           let files: Vec<String> = info.siblings.iter().map(|s| s.rfilename.clone()).collect();
           eprintln!("Downloading {} files from {}", files.len(), hf_ref.repo_id);
           let mut snapshot_root = None;
           for (i, filename) in files.iter().enumerate() {
               eprintln!("  [{}/{}] {}", i + 1, files.len(), filename);
               let local_path = repo.get(filename)
                   .with_context(|| format!("failed to download {filename}"))?;
               if snapshot_root.is_none() {
                   snapshot_root = Some(derive_snapshot_root(&local_path, filename));
               }
           }
           ```
         - Derive snapshot root:
           ```rust
           fn derive_snapshot_root(file_path: &Path, relative_name: &str) -> PathBuf {
               // file_path is absolute: .../snapshots/{sha}/path/to/file
               // relative_name is: path/to/file
               // Strip the relative name components from the end to get snapshot root
               let depth = relative_name.matches('/').count() + 1;
               let mut root = file_path.to_path_buf();
               for _ in 0..depth {
                   root.pop();
               }
               root
           }
           ```
         - Return: `snapshot_root.ok_or_else(|| anyhow::anyhow!("no files found in repo {}", hf_ref.repo_id))`
