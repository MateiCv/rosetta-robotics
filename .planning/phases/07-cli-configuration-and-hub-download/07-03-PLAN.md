    1. Create `crates/forge-cli/src/commands/quality.rs`:
       - `pub fn run(path: &str, config_path: Option<&Path>, output_format: OutputFormat, save_json: Option<&Path>) -> anyhow::Result<()>`
       - Resolve path and auto-detect format (handles hf:// URLs transparently):
         `let (resolved_path, format_name) = crate::output::resolve_and_detect(path)?;`
       - Get reader: `forge_formats::get_reader(&format_name)?`
       - Load quality config: If `config_path` provided, `QualityConfig::from_yaml(config_path)?`, otherwise `QualityConfig::default()`
       - Create analyzer: `QualityAnalyzer::new(quality_config)`
       - Call `analyzer.analyze_dataset(reader.as_ref(), &resolved_path)?` to get `QualityReport`
       - Text output: Print summary table:
         ```
         Quality Report: <path>
         Format: <format>
         Episodes: <N>

         Episode Scores:
           Episode    Composite  Smoothness  Dead Actions  Chatter  Static  Timestamps  Saturation  Entropy
           ep_000     0.85       0.92        0.88          0.80     0.95    0.78        0.90        0.75

         Dataset Summary:
           Mean composite: <mean>
           Min composite: <min>
           Flags: <flags>
           Recommendations: <recommendations>
         ```
       - JSON output: `crate::output::print_json(&report)?` — QualityReport derives Serialize
       - Save JSON: If `save_json` is Some, call `analyzer.save_json(&report, save_json_path)?`

    2. Create `crates/forge-cli/src/commands/filter.rs`:
       - `pub fn run(path: &str, output: Option<&str>, min_quality: Option<f64>, dry_run: bool, config_path: Option<&Path>, output_format: OutputFormat) -> anyhow::Result<()>`
       - Resolve path and auto-detect format, get reader AND writer from registry (same format for filter):
         ```rust
         let (resolved_path, format_name) = crate::output::resolve_and_detect(path)?;
         let reader = forge_formats::get_reader(&format_name)?;
         let mut writer = forge_formats::get_writer(&format_name)?;
         ```
       - Build quality config and filter config:
         - `QualityConfig::default()` (or from YAML if config_path provided)
         - `FilterConfig { min_quality, dry_run, ..FilterConfig::default() }` — map `min_quality` CLI arg to `filter_config.min_quality`
         - If `dry_run` is true, pass `output: None` to filter engine
       - Create filter engine: `FilterEngine::new(quality_config, filter_config)`
       - Call filter: `let result = engine.filter(reader.as_ref(), writer.as_mut(), &resolved_path, output_path)?;`
       - Text output: Use `FilterEngine::format_dry_run(&result)` for dry-run, otherwise print:
         ```
         Filter Results:
           Total episodes: <total>
           Kept: <kept>
           Excluded: <excluded>
         ```
       - JSON output: `crate::output::print_json(&result)?` — FilterResult derives Serialize
       - If not dry_run and output is None, error: "Output path required for non-dry-run filter. Use --dry-run to preview or specify <output>."

    1. Create `crates/forge-cli/src/commands/stats.rs`:
       - Define internal `struct FieldStats`:
         ```rust
         struct FieldStats {
             name: String,
             count: usize,
             dims: usize,
             min: Vec<f64>,
             max: Vec<f64>,
             sum: Vec<f64>,
             sum_sq: Vec<f64>,
         }
         ```
         With methods: `fn push(&mut self, values: &[f64])`, `fn mean(&self) -> Vec<f64>`, `fn std(&self) -> Vec<f64>`
         Use Welford-like streaming: first push initializes min/max/sum/sum_sq, subsequent pushes update.

       - Define serializable output struct:
         ```rust
         #[derive(Serialize)]
         struct StatsReport {
             path: String,
             format: String,
             total_episodes: usize,
             total_frames: usize,
             episode_lengths: EpisodeLengthStats,
             fields: Vec<FieldStatsOutput>,
         }
         ```

       - `pub fn run(path: &str, output_format: OutputFormat) -> anyhow::Result<()>`:
         - Resolve path and auto-detect format (handles hf:// URLs transparently):
           `let (resolved_path, format_name) = crate::output::resolve_and_detect(path)?;`
         - Get reader: `let reader = forge_formats::get_reader(&format_name)?;`
         - Read episodes via `reader.read_episodes(&resolved_path)?`
         - Iterate over all episodes and frames:
           - Track episode count and per-episode frame counts for episode length stats
           - For action and state fields (`frame.action`, `frame.state`): resolve the LazyArray to get f64 values, feed to FieldStats accumulators
           - Use `lazy_array.load()?` to get `&Vec<f64>` — this is the LazyArray API (see `crates/forge-core/src/lazy.rs`)
           - Shape is available via `lazy_array.shape()` returning `&[usize]`
         - Compute episode length distribution: min, max, mean, std of episode lengths
         - Text output:
           ```
           Dataset Statistics: <path>
           Format: <format>
           Episodes: <N>
           Total frames: <N>

           Episode Lengths:
             Min: <min>  Max: <max>  Mean: <mean>  Std: <std>

           Field Statistics:
             Field          Dims  Min         Max         Mean        Std
             action         7     -1.000      1.000       0.012       0.234
             observation    14    -3.140      3.140       0.523       1.102
           ```
         - JSON output: Serialize StatsReport to JSON

       - Handle the case where no action/state fields exist gracefully (print "No numeric fields found")
