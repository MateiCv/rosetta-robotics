```rust
pub struct FilterEngine {
    quality_config: QualityConfig,
    filter_config: FilterConfig,
    analyzer: QualityAnalyzer,
}
```

`impl FilterEngine`:

`pub fn new(quality_config: QualityConfig, filter_config: FilterConfig) -> Self`:
- Create QualityAnalyzer from quality_config clone.

**Path validation helper:**
`fn validate_paths(source: &Path, output: &Path) -> ForgeResult<()>`:
- Canonicalize both paths (use `std::fs::canonicalize` for source which exists, and for output use parent canonicalization + filename since output may not exist yet).
- If canonical source == canonical output: return `Err(ForgeError::Config("output path must differ from source path".into()))`.
- If output is ancestor of source or source is ancestor of output: return `Err(ForgeError::Config("output path must not overlap with source path".into()))`.
- Per user decision: "Copy-only: filtering always writes to a new output path. Source dataset is never modified. Refuse to overwrite source."

**Lazy metadata pre-filtering (QUAL-15):**
`fn should_skip_by_metadata(&self, episode: &Episode, dataset_info: &DatasetInfo) -> Option<FilterDecision>`:
- Check manual overrides first:
  - If episode index is in `filter_config.keep_episodes`: return `Some(FilterDecision::Keep("manual keep override"))`.
  - If episode index is in `filter_config.remove_episodes`: return `Some(FilterDecision::Remove("manual remove override"))`.
- Check metadata-level heuristics before loading full frame data:
  - If `episode.frames.is_empty()`: return `Some(FilterDecision::Remove("empty episode"))`.
  - If episode has no action data on first frame (`episode.frames[0].action.is_none()`): depending on which metrics require action, this might indicate the episode will score poorly. Return None (continue to full analysis) since we want the metrics to handle this gracefully.
- Return None (needs full analysis).

`FilterDecision` enum: `Keep(&'static str)`, `Remove(&'static str)`, representing reason.

**Core filter method:**
`pub fn filter(&self, reader: &dyn FormatReader, writer: &mut dyn FormatWriter, source: &Path, output: Option<&Path>) -> ForgeResult<FilterResult>`:
- If `output.is_some()`: validate_paths(source, output.unwrap()).
- Call `reader.inspect(source)` for dataset metadata.
- Call `reader.read_episodes(source)` for episode iterator.
- Initialize result tracking: kept_ids, excluded_ids, exclusion_reasons.
- For each episode from the iterator:
  - **Lazy pre-filter (QUAL-15):** call `should_skip_by_metadata()`. If Keep, add to kept list. If Remove, add to excluded with reason. If None, continue to full analysis.
  - **Full quality analysis:** call `self.analyzer.analyze_episode(&episode, dataset_info.fps)`.
  - **Evaluate against thresholds:**
    - `evaluate_episode(quality: &EpisodeQuality) -> (bool, Vec<String>)`:
      - Check composite threshold: if `filter_config.min_quality.is_some()` and `quality.composite_score < Some(threshold)`: fail with reason "composite score below threshold".
      - Check per-metric thresholds (AND logic): for each `(kind, threshold)` in `filter_config.per_metric_thresholds`, look up score in `quality.metric_scores`. If score < threshold: fail with reason "metric_name below threshold".
      - If all pass: return (true, []).
      - If any fail: return (false, reasons).
  - Check manual overrides (keep/remove) -- these override quality-based decisions:
    - If episode index in `keep_episodes`: keep regardless of quality.
    - If episode index in `remove_episodes`: remove regardless of quality.
  - If passing AND output is Some (not dry-run):
    - Call `writer.write_episode(&episode, output.unwrap(), kept_index)`.
    - Increment kept_index.
  - Track kept/excluded counts and reasons.
- If output is Some: call `writer.finalize(output.unwrap(), &filtered_dataset_info)`.
  - `filtered_dataset_info`: clone of original but update `total_episodes` and `total_frames` to reflect filtered counts.
- Build and return FilterResult.

**Dry-run output formatting:**
`pub fn format_dry_run(result: &FilterResult) -> String`:
- Per user decision: "Would keep 42/50 episodes (84%). 8 removed by: smoothness (3), dead actions (5)."
- Count exclusion reasons across all excluded episodes.
- Format as: `"Would keep {kept}/{total} episodes ({pct:.0}%). {removed} removed by: {reasons_str}"`
- If no exclusions: `"Would keep {total}/{total} episodes (100%). None removed."`
