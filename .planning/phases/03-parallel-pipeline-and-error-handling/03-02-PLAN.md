**1. Create `crates/forge-pipeline/src/error_collector.rs`:**

Implement a thread-safe error collector:
```rust
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Mutex;
use std::path::PathBuf;
use forge_core::EpisodeFailure;

/// Thread-safe collector for episode processing failures.
///
/// Used during parallel conversion to gather errors from multiple worker
/// threads. Supports atomic early exit when `fail_on_error` is set.
pub struct ErrorCollector {
    failures: Mutex<Vec<EpisodeFailure>>,
    should_stop: AtomicBool,
    fail_on_error: bool,
}

impl ErrorCollector {
    pub fn new(fail_on_error: bool) -> Self { ... }

    /// Record a failure for the given episode. If fail_on_error is set,
    /// signals all workers to stop via AtomicBool.
    pub fn record(&self, episode_index: usize, error: &forge_core::ForgeError, affected_files: Vec<PathBuf>) {
        // Build context chain from error source chain (use std::error::Error::source())
        let mut context = Vec::new();
        let mut current: Option<&dyn std::error::Error> = std::error::Error::source(&error);
        while let Some(cause) = current {
            context.push(cause.to_string());
            current = cause.source();
        }

        let failure = EpisodeFailure {
            episode_index,
            error: error.to_string(),
            context,
            affected_files,
        };
        self.failures.lock().unwrap().push(failure);
        if self.fail_on_error {
            self.should_stop.store(true, Ordering::Release);
        }
    }

    /// Check whether workers should stop (called in par_iter closure).
    pub fn should_stop(&self) -> bool {
        self.should_stop.load(Ordering::Acquire)
    }

    /// Consume the collector and return all failures sorted by episode index.
    pub fn into_failures(self) -> Vec<EpisodeFailure> {
        let mut failures = self.failures.into_inner().unwrap();
        failures.sort_by_key(|f| f.episode_index);
        failures
    }

    /// Return count of recorded failures.
    pub fn failure_count(&self) -> usize {
        self.failures.lock().unwrap().len()
    }
}
```

**2. Refactor `crates/forge-pipeline/src/convert.rs`:**

The current Converter::convert() is sequential. Refactor to the parallel collect-then-write pattern:

a) Add `use rayon::prelude::*;` and other imports.

b) Add a helper function for memory-throttled thread count:
```rust
fn effective_thread_count(requested: usize) -> usize {
    use sysinfo::System;
    let cpu_count = std::thread::available_parallelism()
        .map(|n| n.get())
        .unwrap_or(1);
    let threads = if requested == 0 { cpu_count } else { requested.min(cpu_count) };

    // Memory-based throttling: estimate ~500MB per parallel episode as baseline
    // (conservative for 1080p video with multiple cameras)
    let mut sys = System::new();
    sys.refresh_memory();
    let available_mb = sys.available_memory() / (1024 * 1024);
    let per_episode_mb: u64 = 500;
    let max_by_memory = (available_mb * 80 / 100 / per_episode_mb).max(1) as usize;

    threads.min(max_by_memory)
}
```

c) Refactor `convert()` method to use two-phase parallel pattern:

**Phase 1 (Parallel Read+Process):** Collect episode indices `0..episode_count`. Use `rayon::ThreadPoolBuilder::new().num_threads(effective_threads).build()` to create a LOCAL pool (not global -- research pitfall #7). Inside `pool.install(|| { ... })`:
- Use `(0..episode_count).into_par_iter().map(|idx| { ... }).collect::<Vec<_>>()`
- Each worker: check `error_collector.should_stop()` first. Then call `reader.read_episodes()` to get iterator, skip to episode `idx` (or better: collect all episodes from iterator first on main thread, then par_iter over the collected Vec).
- IMPORTANT: Since `read_episodes()` returns `Box<dyn Iterator>` which is NOT Send, collect episodes from the iterator INTO a Vec FIRST on the main thread, THEN par_iter over the Vec for the remapping/processing step. This is the safest approach per research open question #1.
- Apply field remapping and camera remapping in the parallel phase (these are pure CPU transformations on owned Episode data).
- Return `(usize, Result<Episode, ForgeError>)` tuples.

**Phase 2 (Sequential Write):** Iterate results in order. For Ok episodes, call `writer.write_episode()`. For Err episodes, call `error_collector.record()`. After all writes, call `writer.finalize()`.

d) Update `ConversionResult` to include `failures: Vec<EpisodeFailure>` instead of `errors: Vec<String>` for richer error reporting. Keep the `errors` field as well for backward compat (populate from failures).

e) After writer.finalize(), check if any failures exist. If so and not quiet/json mode, call `print_failure_summary()`.
