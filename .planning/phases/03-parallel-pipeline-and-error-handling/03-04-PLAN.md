**Step 1: Generalize `prefetch_episodes()` in `prefetch.rs`**

Add a second generic prefetch function `prefetch_items()` that works with any `Send + 'static` item type (not just `ForgeResult<Episode>`). This enables prefetching indexed episode tuples `(usize, Episode)` for the write phase without losing the existing `prefetch_episodes()` function.

```rust
/// Generic prefetch: spawn a background thread that pushes items from an
/// iterator into a bounded crossbeam channel. Returns a Receiver the
/// consumer can iterate over.
pub fn prefetch_items<T, I>(
    items: I,
    buffer_size: usize,
) -> Receiver<T>
where
    T: Send + 'static,
    I: Iterator<Item = T> + Send + 'static,
{
    let (tx, rx) = bounded(buffer_size);
    std::thread::spawn(move || {
        for item in items {
            if tx.send(item).is_err() {
                break;
            }
        }
    });
    rx
}
```

Keep the existing `prefetch_episodes()` as a convenience wrapper calling `prefetch_items()`.

Update `lib.rs` to also export `prefetch_items` if not already re-exported.

**Step 2: Wire prefetch into `convert.rs` write phase**

Current code (around line 231):
```rust

    match episode_result { ... }

```

Change to:
1. Separate `all_results` into two collections: failures (to handle immediately) and successes `Vec<(usize, Episode)>`.
2. Handle all failures first (write marker files, record errors, check fail_on_error).
3. Feed the successes into `prefetch_items()` with `buffer_size = 2` (matching VID-04's ring buffer semantics -- small enough to avoid memory pressure, large enough to hide I/O latency).
4. Consume from the prefetch `Receiver` in the write loop.

The resulting write phase looks like:
```rust
use crate::prefetch::prefetch_items;

// Separate failures from successes for prefetch
let mut successes: Vec<(usize, Episode)> = Vec::new();
for (idx, episode_result) in all_results {
    match episode_result {
        Ok(episode) => successes.push((idx, episode)),
        Err(e) => {
            // Handle failure immediately (marker file, error_collector, etc.)
            // ... existing failure handling code ...
        }
    }
}

// Feed successes through prefetch channel (buffer_size=2 for overlap)
let prefetch_rx = prefetch_items(successes.into_iter(), 2);

// Write from prefetch channel -- background thread stages next episode
// while main thread writes current episode
for (episode_index, episode) in prefetch_rx {
    match writer.write_episode(&episode, output_path, episode_index) {
        Ok(()) => {
            result.total_frames += episode.frame_count();
            result.episodes_converted += 1;
        }
        Err(e) => {
            // ... existing write-failure handling ...
        }
    }
}
```
