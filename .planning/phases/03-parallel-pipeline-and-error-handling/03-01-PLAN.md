```rust
use bytes::Bytes;

#[derive(Debug, Clone)]
pub struct DecodedFrame {
    /// RGB24 pixel data (`width * height * 3` bytes). Arc-backed for zero-copy sharing.
    pub data: Bytes,
    pub width: u32,
    pub height: u32,
    pub frame_index: usize,
}
```

**2. Update `receive_one()` method** in VideoDecoder: After building `data: Vec<u8>` from the scaler output, convert to Bytes:
```rust
let frame = DecodedFrame {
    data: Bytes::from(data),  // Single allocation, then Arc-backed for zero-copy clone
    width: self.width,
    height: self.height,
    frame_index: self.frame_index,
};
```
The `Bytes::from(Vec<u8>)` conversion is zero-copy -- it takes ownership of the Vec's allocation and wraps it in an Arc.

**3. Verify downstream compatibility:** The H264VideoEncoder already accepts `&[u8]` for frame data. `Bytes` implements `Deref<Target=[u8]>`, so `&frame.data` auto-derefs to `&[u8]`.
