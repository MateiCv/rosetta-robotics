  <action>
    Create `.github/workflows/ci.yml` with the following configuration:

    **Triggers:**
    - push to branches: [main, master]
    - pull_request (all branches)

    **Environment:**
    - `CARGO_TERM_COLOR: always`

    **Job: build**
    - Strategy matrix with two entries:
      - `{ os: ubuntu-22.04, name: "Linux" }`
      - `{ os: macos-14, name: "macOS (ARM)" }`
    - `runs-on: ${{ matrix.os }}`
    - `name: Build (${{ matrix.name }})`

    **Steps:**
    1. `actions/checkout@v4`

    2. `actions-rust-lang/setup-rust-toolchain@v1` with:
       - toolchain: stable
       - components: rustfmt, clippy

    3. **Install FFmpeg (Linux):** Conditional on `runner.os == 'Linux'`
       ```
       sudo apt-get update
       sudo apt-get install -y \
         libavcodec-dev libavformat-dev libavutil-dev \
         libavfilter-dev libavdevice-dev libswscale-dev \
         libswresample-dev pkg-config
       ```

    4. **Install FFmpeg (macOS):** Conditional on `runner.os == 'macOS'`
       ```
       brew install ffmpeg pkg-config
       ```

    5. **Install HDF5 (Linux):** Conditional on `runner.os == 'Linux'`
       ```
       sudo apt-get install -y libhdf5-dev
       ```

    6. **Install HDF5 (macOS):** Conditional on `runner.os == 'macOS'`
       ```
       brew install hdf5
       ```

    7. **Validate FFmpeg linkability:**
       ```
       pkg-config --libs libavcodec libavformat libavutil
       ```
       This step confirms FFmpeg development libraries are discoverable by pkg-config, which is what the `ffmpeg-next` crate uses to find FFmpeg in Phase 2+.

    8. **Validate HDF5 linkability:**
       ```
       pkg-config --libs hdf5 || echo "HDF5 pkg-config not available, checking alternative..."
       ls /usr/lib/x86_64-linux-gnu/libhdf5* 2>/dev/null || ls /opt/homebrew/lib/libhdf5* 2>/dev/null || echo "HDF5 library files found via filesystem"
       ```
       HDF5 may not have pkg-config files on all platforms. The filesystem check is a fallback validation.

    9. **Check formatting:** `cargo fmt --all -- --check`

    10. **Clippy lints:** `cargo clippy --workspace --all-targets -- -D warnings`

    11. **Build workspace:** `cargo build --workspace`

    12. **Run tests:** `cargo test --workspace`

    13. **Smoke test -- forge version:** `cargo run -p forge-cli -- version`
        This validates the binary runs end-to-end and can detect FFmpeg on the CI runner.

    **Important CI design notes:**
    - Do NOT use `actions-rs/*` actions (unmaintained per research). Use `actions-rust-lang/setup-rust-toolchain@v1`.
    - Do NOT use `AnimMouse/setup-ffmpeg` yet. Start with native apt/brew packages. If FFmpeg version mismatch occurs with `ffmpeg-next` in Phase 2, upgrade to Ubuntu 24.04 or add PPA (per research recommendation).
    - Keep the CI job simple -- single job with matrix, not separate jobs for lint/build/test. This matches the solo-developer workflow.
  </action>
