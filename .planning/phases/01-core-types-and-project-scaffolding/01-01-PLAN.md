All with Debug, Clone, Serialize, Deserialize.

       **lazy.rs**: LazyImage struct using `std::sync::OnceLock<bytes::Bytes>` (NOT std::cell::OnceCell -- must be Send + Sync from day one per research pitfall #2). Fields: loader as `Mutex<Option<Box<dyn FnOnce() -> Result<Bytes, ForgeError> + Send>>>`, cached: OnceLock<Bytes>, height: u32, width: u32, channels: u8. Methods: new(loader, h, w, c), from_bytes(data, h, w, c), load() -> ForgeResult<&Bytes>, shape() -> (u32, u32, u8), is_loaded() -> bool. LazyArray struct similarly: loader as `Mutex<Option<Box<dyn FnOnce() -> Result<Vec<f64>, ForgeError> + Send>>>`, cached: OnceLock<Vec<f64>>, shape: Vec<usize>, dtype: Dtype. Methods: new(loader, shape, dtype), from_vec(data, shape, dtype), load() -> ForgeResult<&Vec<f64>>, shape() -> &[usize], dtype() -> Dtype, is_loaded() -> bool. Both types MUST be Send + Sync. Use Mutex to wrap the FnOnce loader since OnceLock::get_or_init requires a non-consuming closure but we need FnOnce. The pattern: in load(), take the loader from Mutex, call it, store result in OnceLock.
