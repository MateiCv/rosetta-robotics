```rust
pub struct HubUploader {
    token: String,
    endpoint: String, // default "https://huggingface.co"
}
```

Implement these methods on HubUploader:

1. `pub fn new(token: String) -> Self` -- sets endpoint to "https://huggingface.co"

2. `pub fn create_repo(&self, repo_id: &str, private: bool) -> Result<()>` -- POST to `{endpoint}/api/repos/create` with JSON body `{"type": "dataset", "name": repo_id, "private": private}`. Include `Authorization: Bearer {token}` header. Handle 409 Conflict (repo already exists) as Ok -- not an error. Return descriptive error for 401/403 (wrong token permissions: "Upload requires a write-scoped token").

3. `fn classify_files(base: &Path) -> Result<(Vec<FileEntry>, Vec<FileEntry>)>` -- Walk the directory recursively, collect all files as FileEntry { relative_path: String, absolute_path: PathBuf, size: u64 }. Split into small (<10MB) and large (>=10MB) vectors. Skip hidden files (.git, .gitattributes). The 10MB threshold is `const LFS_THRESHOLD: u64 = 10 * 1024 * 1024`.

4. `fn compute_sha256(path: &Path) -> Result<String>` -- Read file in 8KB chunks, compute SHA-256 using sha2 crate, return hex-encoded hash string.

5. `fn upload_lfs_files(&self, repo_id: &str, files: &[FileEntry]) -> Result<Vec<LfsPointer>>` -- For each large file:
   a. Compute SHA-256 and file size
   b. POST to `{endpoint}/api/datasets/{repo_id}/lfs/objects/batch` with JSON `{"operation": "upload", "objects": [{"oid": sha256, "size": size}]}` to get presigned upload URL
   c. Read the response JSON to extract the upload URL from `objects[0].actions.upload.href`
   d. PUT file bytes to the presigned URL with `Content-Type: application/octet-stream`
   e. Return LfsPointer { relative_path, oid (sha256), size } for each file
   Print progress: "  Uploading (LFS) [{i}/{total}] {relative_path} ({size_mb:.1} MB)"

6. `pub fn upload_folder(&self, repo_id: &str, local_path: &Path) -> Result<()>` -- Orchestrates the full upload:
   a. Call classify_files to enumerate small and large files
   b. Print summary: "{N} files ({M} via LFS)"
   c. Upload LFS files first via upload_lfs_files()
   d. Build the commit payload as multipart form data using ureq. The commit endpoint is `POST {endpoint}/api/datasets/{repo_id}/commit/main`. The payload format follows HuggingFace's commit API:
      - Header `Content-Type: multipart/form-data`
      - For each small file: a form part with name matching the JSON operation and file content as the part body
      - For each LFS pointer: include the LFS pointer file content (the standard git-lfs pointer format: `version https://git-lfs.github.com/spec/v1\noid sha256:{oid}\nsize {size}\n`)

      **Important:** The exact multipart format should be modeled after the Python huggingface_hub library's `_prepare_commit_payload()`. The commit API expects:
      - A JSON header part with `Content-Disposition: form-data; name="header"` containing the operation list as JSON
      - For each "addOrUpdate" operation for regular files, a binary part with `Content-Disposition: form-data; name="{path}"; filename="{path}"` containing file bytes
      - For LFS files, the operation header references the LFS pointer content instead

      If the exact multipart format proves tricky, use an alternative approach: make individual file upload calls rather than a single commit. Test with a small dataset first.
   e. Print "Upload complete: {repo_id}"

Include unit tests:
- test_classify_files with a tempdir containing files of various sizes
- test_compute_sha256 with known input/output
- test LFS threshold classification (file at exactly 10MB boundary)

Do NOT use async/tokio. Use ureq's synchronous API throughout. Do NOT shell out to git or git-lfs.

  ```rust
  pub fn run_upload(path: &str, repo: &str, token: Option<&str>, private: bool) -> Result<()> {
      // Validate local path exists and is a directory
      let local_path = std::path::Path::new(path);
      if !local_path.exists() {
          anyhow::bail!("Dataset path does not exist: {path}");
      }
      if !local_path.is_dir() {
          anyhow::bail!("Dataset path is not a directory: {path}");
      }

      // Require a token for upload
      let token = token.ok_or_else(|| {
          anyhow::anyhow!(
              "Upload requires authentication. Set HF_TOKEN environment variable \
               or pass --token <token>.\n\
               Get a write-scoped token at: https://huggingface.co/settings/tokens"
          )
      })?;

      let uploader = crate::hub_upload::HubUploader::new(token.to_string());

      // Create repo (idempotent -- 409 is handled as success)
      eprintln!("Creating repository: {repo}");
      uploader.create_repo(repo, private)?;

      // Upload all files
      eprintln!("Uploading dataset from: {path}");
      uploader.upload_folder(repo, local_path)?;

      // Print verification hint
      eprintln!();
      eprintln!("Verify: forge hub download {repo}");
      eprintln!("   URL: https://huggingface.co/datasets/{repo}");

      Ok(())
  }
  ```
