<task type="auto">
  <name>Task 1: Implement TFRecord binary parser with GZIP detection</name>
  <files>crates/forge-formats/src/rlds/mod.rs, crates/forge-formats/src/rlds/tfrecord.rs, crates/forge-formats/src/lib.rs</files>
  <action>
1. Create `crates/forge-formats/src/rlds/` directory with `mod.rs`, `tfrecord.rs`.

2. In `tfrecord.rs`, implement low-level TFRecord parsing:
   - Use the `tfrecord` crate (v0.15) OR hand-roll the parser. Decision: try `tfrecord` crate first. If it proves too heavyweight or has dependency issues, fall back to hand-rolling with `prost` + `crc32c`.
   - TFRecord binary format per record:
     ```
     uint64    length (little-endian)
     uint32    masked_crc32_of_length
     byte      data[length]
     uint32    masked_crc32_of_data
     ```
   - CRC masking: `masked = ((crc >> 15) | (crc << 17)).wrapping_add(0xa282ead8)`
   - Implement `read_tfrecord(reader: &mut impl Read) -> ForgeResult<Vec<u8>>`:
     a. Read 8 bytes -> length (u64 LE)
     b. Read 4 bytes -> length CRC (validate with crc32c)
     c. Read `length` bytes -> data
     d. Read 4 bytes -> data CRC (validate with crc32c)
     e. Return data bytes
   - Implement `TFRecordIterator` that wraps a reader and yields records:
     ```rust
     pub struct TFRecordIterator<R: Read> {
         reader: R,
     }
     impl<R: Read> Iterator for TFRecordIterator<R> {
         type Item = ForgeResult<Vec<u8>>;
     }
     ```
   - GZIP detection and decompression:
     a. Before iterating, check first 2 bytes of the file: `0x1f 0x8b` = GZIP
     b. If GZIP, wrap the reader in `flate2::read::GzDecoder`
     c. ZLIB: first byte `0x78` = ZLIB, wrap in `flate2::read::ZlibDecoder`
     d. Otherwise, read raw
   - Implement `open_tfrecord_file(path: &Path) -> ForgeResult<TFRecordIterator<Box<dyn Read>>>`:
     a. Open file, detect compression, return appropriate iterator

3. Implement protobuf decoding for `tf.train.Example`:
   - Use `prost` to decode the `Example` protobuf message from raw bytes
   - The `tfrecord` crate may provide pre-compiled protobuf types for `Example`, `Features`, `Feature`, `BytesList`, `FloatList`, `Int64List`
   - If hand-rolling, define the protobuf types with prost:
     ```rust
     // tf.train.Example { features: Features }
     // Features { feature: HashMap<String, Feature> }
     // Feature { kind: oneof { bytes_list, float_list, int64_list } }
     ```
   - `decode_example(data: &[u8]) -> ForgeResult<HashMap<String, FeatureValue>>`:
     a. Decode protobuf Example
     b. Extract each feature by name
     c. Map to `FeatureValue` enum: `Bytes(Vec<Vec<u8>>)`, `Float(Vec<f32>)`, `Int64(Vec<i64>)`

4. In `mod.rs`: re-export key types.
5. In `crates/forge-formats/src/lib.rs`: add `#[cfg(feature = "rlds-format")] pub mod rlds;`.
  </action>

<task type="auto">
  <name>Task 2: Implement RLDS FormatReader with episode boundary detection</name>
  <files>crates/forge-formats/src/rlds/reader.rs, crates/forge-formats/src/rlds/mod.rs</files>
  <action>
1. In `reader.rs`, create `RLDSReader` unit struct implementing `FormatReader`:
   - `format_name()` returns "rlds".
   - `can_read(path)`: check for `.tfrecord` files in the directory tree (glob `**/*.tfrecord*`).
   - `inspect(path)`:
     a. Look for `dataset_info.json` (TFDS metadata) at `{path}/dataset_info.json` or `{path}/*/dataset_info.json`
     b. If found, parse it for feature descriptions, split info, dataset name
     c. If not found, open first .tfrecord shard, decode first Example, infer schema from feature keys and types
     d. Build DatasetInfo: format "rlds", fields from feature keys, cameras from image features
     e. Detect image features: keys containing "image" with bytes_list type are likely images
     f. Detect action/state: keys named "action", "observation/*", "discount", "reward"
   - `read_episodes(path)`:
     a. Find all .tfrecord shard files, sort by name (shards are typically numbered: *-00000-of-00005.tfrecord)
     b. RLDS episode structure detection:
        - **is_first/is_last pattern**: Each Example (step) has boolean features `is_first` and `is_last`. Group steps into episodes by splitting on `is_first=true`.
        - **Separate episode dirs**: Some datasets have `episodes/` directory with sub-dirs per episode
     c. Iterate shards sequentially, parsing each TFRecord into an Example
     d. For each step (Example), create a Frame:
        - Image features (bytes_list): create LazyImage with ImageEncoding detected from first bytes (JPEG/PNG magic)
        - Float features: map to LazyArray (action, observation.*)
        - Int64 features: map to LazyArray with Dtype::Int64
        - String features (bytes_list with text): store as frame.metadata
     e. Group frames into Episodes:
        - Track `is_first` boolean: when true, start new Episode
        - If no is_first/is_last markers, each Example is its own episode (single-step episodes)
     f. Preserve ALL features in frame.metadata, including:
        - `is_first`, `is_last` -> metadata booleans
        - `reward` -> metadata float
        - `discount` -> metadata float
        - `language_instruction` -> metadata string
        - Any unknown features -> metadata JSON
     g. Lenient reading: if a shard file is corrupt or unreadable, skip it with ReadWarning, continue with remaining shards

2. Implement `FormatDetector` for `RLDSDetector`:
   - Confidence scoring:
     a. `.tfrecord` files found in directory: +0.5
     b. `dataset_info.json` present: +0.3
     c. TFDS-style directory structure (`train/`, `test/`, shard files): +0.2
   - Evidence strings for each check

3. In `mod.rs`: re-export `RLDSReader` and `RLDSDetector`.

Per user decision: preserve everything including reward, discount, language_instruction. Original timestamps (step indices) kept as-is. Images passed through as compressed bytes (JPEG/PNG) with ImageEncoding set.
  </action>

`cargo build -p forge-formats --features rlds-format` compiles. `cargo test -p forge-formats` passes. Unit tests: test episode boundary detection from is_first/is_last markers. Test feature-to-frame mapping.
  </verify>
