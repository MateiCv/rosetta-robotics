  <action>
Create `crates/forge-formats/src/rlds/writer.rs` implementing `FormatWriter` for RLDS/TFRecord format.

**RLDSWriter struct:**
- Fields: `episodes_written: Vec<WrittenEpisodeInfo>` (episode_index, num_frames, shard_path), `deterministic: bool`
- Constructor: `RLDSWriter::new()` with empty state

**write_episode implementation:**
- One TFRecord shard per episode: `train/data-{episode_index:05}-of-NNNNN.tfrecord`
- Create output dirs: `output_path/train/`
- Use `tfrecord::record_writer::ExampleWriter` (not hand-rolled CRC) per research pitfall 1
- For each frame, build a `tfrecord::protobuf::Example` with features map:
  - `is_first`: Int64List with 1 for first frame, 0 otherwise (RLDS convention, pitfall 7)
  - `is_last`: Int64List with 1 for last frame, 0 otherwise
  - `action`: FloatList from `frame.action.load()` cast to f32 (if present)
  - `observation/state` or `state`: FloatList from `frame.state.load()` cast to f32 (if present)
  - Image features: BytesList containing encoded image bytes from `frame.images` entries. Use `image.load_encoded()` if available, otherwise `image.load()` raw bytes
  - Metadata features: Iterate `frame.metadata` and map serde_json::Value to appropriate Feature types (String -> BytesList, Number -> FloatList or Int64List, Array of numbers -> FloatList)
- Call `writer.send(example)` for each frame, then `writer.flush()`
- Track episode info for finalize

**finalize implementation:**
- Update shard filenames: rename `data-NNNNN-of-NNNNN` with correct total shard count
- Write `dataset_info.json` in TFDS format with:
  - `name`: from `dataset_info.metadata` or "converted_dataset"
  - `description`: from metadata or empty
  - `splits`: `{"train": {"name": "train", "numShards": N, "numExamples": total_episodes}}`
  - `features`: inferred from first episode's frame structure
- Sort JSON keys if `deterministic` is true (use `sort_json_keys` pattern from v3 writer)

**set_deterministic:** Store flag for deterministic JSON output.

**Tests (in writer.rs #[cfg(test)] mod tests):**
- `writer_produces_valid_tfrecord`: Create synthetic episode with 5 frames (action, state, 1 image), write with RLDSWriter, verify shard file exists, read back with `ExampleReader` or the RLDS reader, verify frame count and is_first/is_last markers
- `writer_preserves_metadata_features`: Write episode with metadata entries, read back, verify preservation

Update `crates/forge-formats/src/rlds/mod.rs`:
- Add `pub mod writer;`
- Add `pub use writer::RLDSWriter;`

Create `crates/forge-formats/src/lerobot_v2/writer.rs` implementing `FormatWriter` for LeRobot v2 format.

**LeRobotV2Writer struct:**
- Fields: mirror LeRobotV3Writer structure -- `fps: u32`, `robot_type: String`, `episodes_written: Vec<WrittenEpisode>`, `total_frames: usize`, `action_dim: Option<i32>`, `state_dim: Option<i32>`, `cameras: Vec<(String, u32, u32, u8)>`, `tasks: Vec<String>`, `deterministic: bool`, `chunks_size: usize`
- Constructor: `LeRobotV2Writer::new(fps, robot_type)` defaulting chunks_size to 1000

**write_episode implementation:**
- Key difference from v3: file naming uses `episode_{episode_index:06}` not `file-{N:03}`
- Parquet path: `data/chunk-{chunk:03}/episode_{episode_index:06}.parquet`
- Video path: `videos/{camera_key}/chunk-{chunk:03}/episode_{episode_index:06}.mp4`
- Reuse the same Parquet schema building and Arrow RecordBatch construction from v3 (import `parquet_io` from lerobot_v3 module or duplicate locally). Use `lerobot_v3::parquet_io::build_data_schema()` and `write_parquet_file()` since the Parquet schema is the same between v2 and v3
- Reuse `H264VideoEncoder` from forge-video for MP4 encoding (same as v3)
- On first episode, capture action_dim, state_dim, cameras (same as v3 pattern)
- Track written episodes for finalize

**finalize implementation:**
- Write `meta/info.json` using `V2InfoJson` struct from `lerobot_v2::info` module with:
  - `codebase_version: "v2.0"` (critical difference from v3's "v3.0", pitfall 6)
  - `data_path`: `data/chunk-{chunk_index:03d}/episode_{episode_index:06d}.parquet`
  - `video_path`: `videos/{video_key}/chunk-{chunk_index:03d}/episode_{episode_index:06d}.mp4`
  - Populate all required v2 fields: fps, robot_type, total_episodes, total_frames, splits, features
- Write `meta/tasks.jsonl` (same format as v3)
- Write `meta/stats.json` placeholder (same as v3)
- Write episode metadata Parquet files under `meta/episodes/chunk-NNN/file-000.parquet` (same as v3)
- Sort JSON keys for deterministic output

**Tests (in writer.rs #[cfg(test)] mod tests):**
- `writer_produces_v2_dataset`: Create 2 synthetic episodes (action, state, image), write with LeRobotV2Writer, verify:
  - Data parquet at `data/chunk-000/episode_000000.parquet` exists (v2 naming)
  - Video at `videos/observation.images.top/chunk-000/episode_000000.mp4` exists (v2 naming)
  - `meta/info.json` has `codebase_version: "v2.0"` and correct data_path/video_path templates
- `writer_round_trip`: Write with LeRobotV2Writer, read back with LeRobotV2Reader, verify episode count and frame data match within f32 precision
